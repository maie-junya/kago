# ロードマップ

## 前提

- Web アプリを作りながら、フロントからインフラまで網羅的に学ぶ。機能は少しずつ増やしていく
- インフラは、クラウドのマネージドサービスを使いこなせる状態を目標にする
- 実務に近く、かつ安く進める
- 期間は決めず、完了条件で区切る

## フェーズ

- 各フェーズは小さくし、アプリを変えたら本番に出して終える
- 依存関係の順に並べ、関連する作業はまとめる
- ALB と CD は、手動で一度やってから入れる
- 認証は商品の作成・編集・削除より前に入れ、認証のない書き込みを本番に出さない
- テストは必要になったところで足す。Next.js は必要になった分だけ学ぶ
